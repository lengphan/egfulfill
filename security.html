Security

Last updated: January 2024

We take the security of your account, designs, and order data seriously. This page summarizes the safeguards we use to protect your information.

Encryption

Data is encrypted in transit using TLS and at rest in our databases and file storage. Payment details are handled by PCI-compliant processors — we never store full card numbers.

Access control

Access to production systems is limited to authorized staff on a least-privilege basis, protected by strong authentication and audited regularly.

Infrastructure

We host on reputable cloud providers with managed backups, network isolation, and continuous monitoring for anomalous activity.

Incident response

We maintain procedures to detect, investigate, and respond to security incidents, and will notify affected users where required by law.

Report a vulnerability

Found a security issue? Email security@egfulfill.com and we’ll work with you to resolve it responsibly.

Questions? Contact us at legal@egfulfill.com.
